# Participation

Keep discussions respectful and focused on code, behavior, evidence, and scope.
Harassment, threats, personal attacks, doxxing, discrimination, and deliberate
disruption are unacceptable. Protect private information and never post
credentials or unredacted user data.

Follow [CONTRIBUTING.md](CONTRIBUTING.md) for proposing changes. Repository
maintainers may moderate participation using their configured GitHub access.
Use an explicitly provided private contact route for sensitive concerns; GitHub
does not supply a general private messaging channel. For vulnerability reports,
follow [SECURITY.md](SECURITY.md).
